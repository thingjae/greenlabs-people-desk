그린랩스 피플 데스크 v1.0
채용 진행 관리 + 사내 규정 질문 답변 · 웹 서비스
데모 greenlabs-people-desk.vercel.app

6개 포지션 채용과 하루 20건의 규정 문의를 함께 맡은 스타트업 피플팀 매니저가, 월요일 아침 채용 사이트마다 형식이 다른 지원서 수십 통을 스프레드시트로 옮기다 면접 확정 메일을 놓치는 순간을 위한 도구입니다.

대표 업무 한 건 피플팀 매니저가 채용 사이트에서 온 지원서 1건을 등록하고, 채용 보드에서 그 지원자의 다음 할 일을 확인합니다. 샘플: 가상 원티드 지원 메일(정다온 · 백엔드 개발자) → 완료 화면: P01 "서류" 칸 카드 + 상세의 단계 이력 "지원서 자동 입력 승인"

주요 기능과 확인할 화면

기능사용자가 하는 일달라지는 점확인할 화면 · 보여줄 근거
① 지원서 자동 입력지원서 메일 본문 붙여 넣기, 채워진 값 확인옮겨 적기 대신 확인만. 같은 이메일 지원자 자동 표시"지원서 등록 대기" · 가상 지원서로 6개 항목 추출, 등록, 중복 표시 확인
② 채용 보드포지션 탭을 열고 배지 칩을 눌러 거르기메일을 뒤지지 않고 다음 할 일과 담당자를 봄"채용 보드" · 가상 지원자 400명에서 안내 기한 초과 7건, 과제 기한 초과 6건 표시
③ 규정 질문직원이 질문, 피플팀은 개정 문서를 올림근거 위치와 함께 답. 문서끼리 다르면 개정일 최신 문서를 따르고 차이를 알림"규정 질문" · "문서 관리" · "문의함" · 개정판 업로드 후 답변 변경 확인

그 밖에: 면접 평가(제출 전 다른 평가 잠금) · 면접 일정(모두 가능한 시간만) · 통계(앞 단계 대비 통과율) · 포지션 단위 열람 권한

왼쪽: 등록 대기 — 원문과 AI가 채운 값, 승인·반려 / 오른쪽: 등록한 지원자가 보드 "서류" 칸에 나타남 (로컬 시험 화면, 가상 데이터)

고객이 멈추거나 고칠 수 있는 시점

  • 지원서: AI 값 수정 · 반려. 승인 전에는 지원자로 등록되지 않음
  • 단계 이동·불합격 확정: 피플팀 버튼으로만
  • 불합격 메일: 초안을 고친 뒤 발송 처리
  • 민감·근거 없는 질문: 자동 답 없이 피플팀이 답 작성
  • 문서: 잘못 올리면 이전 버전으로 되돌리기
  • 평가: 제출 후 수정 가능, 수정 이력 남음

적용 조건

  • 자료: 규정 PDF+개정일, 지원자 엑셀(포지션·이름·이메일·연락처·지원 경로·현재 단계), 평가 기준표, 면접관 배정표
  • 권한: 피플팀 계정, 면접관-포지션 배정. 사내 로그인(SSO) 연동 확인 필요
  • 지원 범위: 웹 화면, 데이터 1회 이관, 기준값(안내 기한·보관 기간 등) 설정
  • 미포함: 메일함 자동 수집, 실제 메일 발송, 슬랙, 온보딩 요청

담당자와 비용

  • 제작·기술 지원: 정명재 (연락처 확인 필요)
  • 고객 측 운영 담당(문서 업로드·기준값): 확인 필요
  • 비용: AI 사용료(OpenAI, 사용량 과금) · 서버·DB(Railway) · 화면(Vercel). 금액·부담 주체 확인 필요. 데모는 체험 크레딧으로 운영

근거

  • 직접 확인: 시험 56개 중 통과 54·부분 1·실패 0(가상 데이터) / 첫 방문→등록→다시 찾기→초기화(로컬 11-19) / 배포 주소 로그인·AI 답변·개정 반영(11-13)
  • 미확인: 실제 채용 메일 원문 · 규정 150쪽 규모 · 동시 사용 · 배포 화면의 초기화·되돌리기
  • 적용 때 측정: 지원서 1건 등록 시간 · 진행 확인용 메일 검색 횟수 · 안내 5영업일 준수율 · 일정 확정 메일 왕복 수 · 자동 답변/이관 비율 · 정정한 답변 수

2

샘플

가상 지원자 400명, 포지션 6개, 규정 문서 3종이 미리 들어 있습니다. 이번 체험에서는 "원티드 형식" 예시 지원서(정다온 · 백엔드 개발자)를 씁니다.

3

행동

  1. 왼쪽 메뉴 지원서 등록 대기 → 예시 원티드 형식 → 항목 채우기
  2. 노란 칸이 있으면 값을 확인·수정 → 확인했고 등록 (멈추고 싶으면 반려: 지원자로 등록되지 않음)
  3. 채용 보드 → P01 백엔드 개발자 → 검색창에 "정다온"
  4. 카드를 눌러 지원자 상세를 엽니다
✓

성공을 판단할 화면

  • 보드 "서류" 칸에 정다온 카드, 아래에 "▶ 서류 검토 · 피플팀"
  • 지원자 상세 단계 이력에 "지원서 자동 입력 승인"
  • 초기화 직후 첫 등록이면 지원자 번호는 A0401

고객이 멈추거나 고칠 수 있는 시점 (대본 0:30 · 0:45)

  • AI가 채운 값은 승인 전까지 고치거나 반려할 수 있음
  • 불합격 메일은 초안 → 피플팀 확인 후 발송
  • 민감·근거 없는 질문은 사람이 답함

말하면 안 되는 것

  • "메일함에서 자동으로 가져온다" — 지금은 붙여 넣기 방식 (메일함 연동은 다음 단계)
  • "시간이 ○○% 줄어든다" — 측정 전. 적용 후 함께 재기로 제안
  • "앱에서 메일을 보낸다" — 앱은 초안과 발송 기록만
  • "2주 시범 운영" 기간·비용 조건 — 확인 필요

예상 질문 한 줄 답

  • 틀린 답을 하면? 올린 문서 안의 내용으로만 답하고, 근거를 못 찾으면 피플팀에 넘깁니다. 모든 답변은 문의함에 남습니다.
  • 개인정보는? 면접관은 담당 포지션만, 연봉·이전 지원 기록은 피플팀만 봅니다. 보관 기간이 지나면 파기 대상으로 표시합니다.
  • 비용은? AI 사용료와 서버 비용이 사용량에 따라 듭니다. 금액과 부담 주체는 확인 필요.

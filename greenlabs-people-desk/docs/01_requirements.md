# 요구사항 정의서 — 20. 그린랩스 피플팀

- 작성: 정명재 · 2026-11-13
- 근거: 고객사 자료(소개·고충 장면·인터뷰·기본 요구사항·제공 자료), 고객 인터뷰실 질의 33건, 브리핑 후 고객 피드백 2건

## 1. 고객 개요

| 항목 | 내용 |
|---|---|
| 회사 | 직원 90명 소프트웨어 스타트업 |
| 담당 조직 | 피플팀 3명 (피플팀장 1, 매니저 2: 서 매니저·이 매니저) |
| 채용 방식 | 여러 채용 사이트에 공고 → 지원서를 이메일로 받아 스프레드시트로 관리, 면접 일정은 메일로 하나씩 조율 |
| 직원 문의 | 휴가·복지·경비·재택 질문이 슬랙으로 피플팀에 들어옴 (하루 약 20건) |
| 보유 자료 | 사내 규정집(150쪽), 복지 가이드·경비 처리 지침(합계 80쪽), 지원자 목록(약 400명), 포지션별 면접 평가 기준표 → 실제 파일 대신 가상 예시를 만들어 쓰라고 함 |

## 2. 고객의 말 (원문 요약)

| 말한 사람 | 말 |
|---|---|
| 피플팀장 | 채용이 동시에 6개 포지션이 돌아가요. 지원자가 어느 단계에 있는지 한눈에 안 보여요 |
| 서 매니저 | 단계는 서류, 과제, 1차 면접, 2차 면접, 처우 협의, 입사예요. 단계마다 담당자가 달라요 |
| 서 매니저 | 면접 일정 맞추는 데 메일이 열 번 오가요 |
| 개발팀장 | 면접 평가를 각자 따로 적어서 나중에 모으기 힘들어요. 평가 기준도 사람마다 달라요 |
| 피플팀장 | 탈락 안내를 제때 못 해서 지원자 불만이 생겨요. 회사 평판에 안 좋아요 |
| 이 매니저 | 직원 질문이 하루 20개는 와요. 거의 다 규정집에 있는 내용이에요 |
| 이 매니저 | 규정집이랑 복지 가이드, 경비 처리 지침이 따로 있어요. 서로 겹치는 내용도 있어요 |
| 피플팀장 | 규정이 바뀌면 바뀐 내용으로 답해야 해요. 지난달에 재택 규정이 바뀌었어요 |
| 개발팀장 | 지원자 정보는 그 포지션 면접관만 봐야 해요 |
| 이 매니저 | 개인 사정(건강, 가족 문제)이 섞인 질문은 사람이 직접 답해야 해요 |
| 피플팀장 | 포지션별 지원자 수, 단계별 통과율, 채용 사이트별로 어디서 좋은 지원자가 오는지 보고 싶어요 |
| 서 매니저 | 지원자에게 보내는 메일을 매번 새로 써요. 템플릿이 있으면 좋겠어요 |
| 개발팀장 | 과제 전형 기한을 넘기면 어떻게 할지 매번 고민해요 |
| 서 매니저 | 같은 사람이 다른 포지션에 또 지원하는 경우가 있어요. 예전 기록을 보고 싶어요 |
| 피플팀장 | 입사가 확정되면 온보딩 준비(노트북, 계정)를 시작해야 해요 |
| 이 매니저 | 신입 직원은 규정집이 어디 있는지도 몰라요. 첫 주에 질문이 제일 많아요 |

## 3. 진짜 문제

| # | 진짜 문제 | 근거 |
|---|---|---|
| P1 | **진행 상황을 확인하려고 메일을 뒤지는 시간.** 지원자가 어느 단계에 있고 다음에 누가 처리해야 하는지 보이지 않음 | 피플팀장이 꼽은 성공 기준 "하나만 꼽으면 메일을 뒤져가며 진행 상황을 확인하는 시간이 줄었으면" |
| P2 | **지원서를 스프레드시트로 옮기는 수작업.** 사이트마다 메일·첨부 형식이 달라 몰리는 날은 오전이 통째로 사라짐 | 서 매니저 답변, 고충 장면(월요일 지원서 70통) — 기본 요구사항에는 없음 |
| P3 | **결정이 늦어지는 연쇄.** 면접 일정 조율(메일 10회) → 평가 지연 → 단계 결정 지연 → 불합격 안내 지연(5영업일 원칙 위반) → 평판 하락 | 서 매니저, 개발팀장("평가가 늦어 결정이 밀린다"), 피플팀장(5영업일 원칙) |
| P4 | **반복 질문에 문서를 찾아 답하는 시간 + 개정 반영 누락 위험.** 문서 3종이 겹치고 개정이 잦음 | 이 매니저, 피플팀장(재택 개정) |
| P5 | **민감 정보 노출 위험.** 지원자 정보·연봉·평가·직원 개인 사정이 섞여 있음 | 개발팀장, 피플팀장(연봉), 이 매니저(민감 질문) |

우선순위: 고객이 채용이 더 급하다고 답함(Q1). 다만 브리핑 후 "직원 질문 답변도 이번 범위에서 함께"를 요청함.

## 5. 정리한 요구사항

### 5-1. 기능 요구사항

| ID | 요구사항 | 출처 | 우선 |
|---|---|---|---|
| R1 | 포지션별 지원자를 단계(서류·과제·1차·2차·처우 협의·입사·불합격·중도 이탈)로 관리하고 한눈에 본다 | 기본 1, Q26 | 필수 |
| R2 | 각 지원자의 **다음 할 일과 다음 담당자**를 보여 준다 | Q33 | 필수 |
| R3 | 면접관이 포지션별 기준표로 평가를 남기고, 피플팀이 모아 본다. 본인 제출 전 타인 평가 비공개 | 기본 2, Q5, Q14 | 필수 |
| R4 | 면접관이 가능 시간을 입력하고, 피플팀이 그중에서 면접 일정을 확정한다 | 기본 3, Q2, Q13 | 필수 |
| R5 | 직원이 규정·복지·경비를 물으면 사내 문서를 근거로 답하고 **문서명·조항·쪽**을 보여 준다 | 기본 4 | 필수 |
| R6 | 새 문서 파일을 개정일과 함께 올리면 바로 답변에 반영된다 | 기본 5, Q3, Q17 | 필수 |
| R7 | 문서끼리 내용이 다르면 **문서 개정일이 최신인 문서**를 따르고 충돌 사실을 함께 표시한다 | Q3, F4 | 필수 |
| R8 | 민감 질문(건강·가족·징계·괴롭힘)과 근거 없는 질문은 자동으로 답하지 않고 피플팀으로 넘긴다 | Q4, Q17 | 필수 |

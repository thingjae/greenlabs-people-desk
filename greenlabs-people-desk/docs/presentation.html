피플팀의 월요일 아침

"백엔드 지원서 70통을 스프레드시트에 옮기고, 면접관 세 명과 메일을 열 번 주고받다가…
슬랙 질문에 답하느라 면접 확정 메일을 잊어버립니다."

직원 90명 · 피플팀 3명 · 6개 포지션 동시 채용 · 직원 질문 하루 20건

인터뷰로 찾은 진짜 문제

  1. 진행 상황 확인에 메일을 뒤지는 시간"하나만 꼽으면 이게 줄었으면" — 피플팀장
  2. 지원서 옮겨 적기"몰리는 날은 오전이 다 지나가요" — 서 매니저 (요구사항엔 없음)
  3. 늦어지는 결정의 연쇄일정 조율 → 평가 지연 → 불합격 안내 5영업일 원칙 위반
  4. 문서 3종이 겹치고 자주 바뀜지난달 재택 규정 개정
  5. 민감 정보포지션별 열람, 연봉, 개인 사정 질문

① 채용 보드: 다음에 누가 무엇을

카드마다 다음 할 일 · 담당자. "안내 기한 초과"를 누르면 5영업일을 넘긴 불합격자만 보입니다 → 초안 확인 → 발송 처리하면 배지가 사라집니다.

② 지원서 자동 입력 (가산점)

사이트마다 다른 지원서를 붙여 넣으면 AI가 항목을 채워 등록 대기로. 피플팀이 확인해야 등록되고, 같은 이메일 지원 기록(A0127·A0265)을 바로 보여 줍니다.

⑤ 통계: 어디서 막히는가

앞 단계 대비 통과율로 병목(빨간색)을 바로 봅니다. 불합격과 중도 이탈을 나누고, 단계가 빠진 데이터는 계산에서 빼고 따로 표시합니다.
